Você vai construir o site institucional one-page do Claudir J. Corrêa, terapeuta integrativo. Este é um projeto de R$ 2.000,00, então o resultado precisa ser premium: muitos detalhes visuais, ícones bem trabalhados, microinterações, hierarquia clara, nada genérico ou "template de duas horas".

Referência de nível de detalhe (abra e analise antes de começar): https://projeto-educa-kids.netlify.app Observe como esse site usa ícones, cartões, camadas, espaçamento e elementos decorativos para parecer rico e premium. Quero o mesmo nível de riqueza visual e quantidade de elementos, mas adaptado 100% para a nossa identidade, cores e conteúdo (não copiar o layout, o texto ou o nicho daquele site, só o padrão de qualidade e densidade de detalhes).

Site one-page (uma página só, âncoras internas, sem rotas para páginas separadas).
Totalmente responsivo (mobile-first), sem quebra de layout em nenhuma largura.
Performance: imagens otimizadas, sem excesso de bibliotecas pesadas.
Sem uso de "Master Terapeuta" em nenhum lugar do site. A identificação correta é sempre "Claudir J. Corrêa — Terapeuta Integrativo".

6. Seção de depoimentos: carrossel automático especial
Os depoimentos serão prints de avaliações do Google (imagens, não texto), enviados pelo Claudir depois. Construa a seção já pronta para receber essas imagens, com este comportamento de carrossel:

Carrossel horizontal com auto-scroll contínuo em loop infinito (efeito marquee), velocidade lenta e constante, sem paradas bruscas.
Ao usuário clicar e segurar (mouse) ou tocar e segurar (touch) em cima do carrossel, o auto-scroll pausa imediatamente.
Enquanto estiver segurando, o usuário pode arrastar livremente para os lados (drag) para navegar pelos depoimentos manualmente.
Ao soltar, o auto-scroll volta a rodar sozinho a partir da posição onde o usuário parou, retomando o loop infinito.
Loop deve ser sem costura (sem "salto" visível quando reinicia).
Cada card do carrossel: altura fixa (ex: 320–380px), largura automática conforme a proporção da imagem (os prints do Google têm proporções variadas), cantos arredondados, leve sombra.
Por enquanto, usar 4 a 6 placeholders de imagem (retângulo com ícone de aspas/estrela e texto "aguardando print do Google") no lugar dos prints reais, estruturados para troca fácil depois.
Nenhum texto de depoimento deve ser inventado ou escrito por você: a seção existe só para receber as imagens reais que o Claudir vai enviar.
